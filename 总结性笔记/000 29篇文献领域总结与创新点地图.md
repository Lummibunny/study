## 二、分方向详解

### 方向 A：充电调度与预约机制（10 篇：①⑨⑩⑪⑬⑱⑲⑳㉑㉖）

**研究主题**：单站/多站的充电任务分配；预约作为"提前锁定容量"的机制；硬时间窗 vs 软时间窗；日前 vs 实时。

**方法与建模**：
- 优化类：MILP（⑨⑲）、机会约束（①）、鲁棒/两阶段鲁棒（⑨⑲㉑）、分布鲁棒 DRO（㉕）
- 在线/学习类：MDP + MCTS（⑳）、DQN/PDQN（⑬）、滚动分配 DRA（①）
- 调度理论：α|β|γ 三域记号、复杂度地图、EDF 特例（⑱ Dolgui）
- 排队/流体：M/M/1、马尔可夫流体休假队列 MFVQ（㉙）

**优势（这个方向做对了什么）**：真实数据（深圳/UrbanEV/ACN）、求解可扩展（19s~30s 级）、不确定性处理规范（预算集+C&CG+对偶定价）。

**缺陷与留白（逐篇作者自认/我识别）**：
- ⑱ 白纸黑字：**再调度、循环时间几乎没人做**；车辆=被动工件
- ⑲：EV 侧爽约、当日动态到达留白；M1 硬窗/M2 软窗是现成对照但都假定守约
- ⑳：**明确不处理取消/改约、司机策略行为（一人约多桩）**；预算分布任意假设
- ㉑：EVCS 策略性报价留白
- ①：取消/不准时是作者自己点名的空白

**我能复用什么**：
- ⑲ 的 **M1 硬窗 vs M2 软窗对照实验框架**（我论文实验的现成基线）+ 其 5.4 万笔公开 EV 交易数据
- ⑳ 的 **Flatrate→VI→Oracle→我的方法 基线阶梯** + 离散化误差证明的写法模板
- ⑱ 的 **α|β|γ 分类**当 Related Work 骨架
- ㉑ 的"**预留的双刃剑**"论证逻辑（预留越多→要兜底的不确定性越大）

**创新点角度**：把 A 的所有模型里"用户准时、守约、同质"三个假设逐一打开（见第五章）。

### 方向 B：车主行为异质与有限理性（4 篇核心：⑧⑪㉒㉔）

**研究主题**：行为异质性有多大、怎么分类、可预测吗；CPT 前景理论刻画充不充/何时充；行为惯性。

**方法与建模**：
- 机器学习实证：13 特征多模型预测 + 逐车误差归因（㉒）
- 计量经济：扩展 MDGEV（地点×时长联合、ψ/γ 两段、状态依赖）（㉔）
- 行为建模：CPT 价值函数+概率权重（⑪母体）、聚类收敛（⑧ NatComm 5 类）
- 规则化行为仿真：激进/中立/保守 + 急迫度 Ur（㉖）

**最硬的几个证据（引用即加分）**：
| 证据 | 数字 | 出处 |
|---|---|---|
| 异质性跨度 | 最好/最差车辆预测 MAE 差 **65 小时** | ㉒ |
| 分用户才是杠杆 | **车辆间差异 ≫ 模型间差异** | ㉒ |
| 行为有惯性 | 习惯持久性 **LLR=903.82**（临界值 45 倍） | ㉔ |
| 理性假设失真 | 平均开始充电 SOC=41%（非理性早充） | ⑪ |
| 最好预测的恰是弹性最大的 | 过夜充 MAPE 202%→15% | ㉒ |

**缺陷与留白**：
- ㉒/㉔ 都把"是否过夜/自报信息"当**外生且诚实**的输入——**谎报动机完全没建模**
- ㉒ 是住宅单桩场景，**无占位冲突、无负外部性**（A/B 的外溢成本正是机制设计存在的理由）
- ⑧ 5 类聚类与㉒的连续异质性维度是正交的，**没人把两者接起来做"分类预约"**

**我能复用什么**：
- ㉒ 的 **Electric Nation 开源数据 + 代码**——直接拿来标定我模型里的用户类型分布、做到达假设的 χ² 检验
- ㉔ 的"**参与+用量**"两阶段结构（是否预约 + 预约时长分开建模）和分类特征清单（最强变量=平台历史订单）
- ⑪ 的 CPT 参数作为我机制的效用底座

**创新点角度**：B 提供的"用户类型"，正是 A 的调度模型和 C 的机制设计缺的状态变量——**把类型内生进预约机制**就是交叉创新。

### 方向 C：机制设计与违约治理（4 篇：⑫㉓㉘ + 方法论⑮）

**研究主题**：怎么定价、怎么设计菜单让用户诚实报需求、违约怎么治理、多主体怎么分蛋糕。

**方法与建模**：
- 在线菜单 + IC（激励相容）分析（⑫ Mathioudaki：单站在线、prompt、truthful 框架）
- 多臂老虎机定价 + Gale-Shapley 匹配 + 声誉惩罚（㉓）
- 双目标 BOMIP + B3M 前沿压缩 + Nash 议价（㉘）
- 模糊集/共识度（⑮ 导师一作 TEDE——群体决策方法论迁移的接口）

**关键发现（㉓ 的可反转结论）**：
- 仅偏好机制福利 **+28.89%**；叠加惩罚反而降到 **+23.49%**
- 根因：惩罚让 DEV 下次更难匹配，但**没有任何补偿流向被坑的 SEV**——惩罚在系统里是纯损

**缺陷与留白**：
- ㉓：无 IC 证明，惩罚公式 P=1±违约率是拍的；违约率 40% 是假设不是估计
- ⑫ 的 truthful 只保证单站在线场景，没做差异化菜单的福利分析
- ㉘：需求如实上报、信息透明，作者自承"未完全捕捉多个自利个体的协同"

**我能复用什么**：
- ㉓ 的 **"无惩罚 / 惩罚销毁 / 惩罚转移"三臂对比实验设计**——我的核心实验可以直接搭这个骨架
- ㉘ 的 **B3M + Nash 议价**工具箱（比 ε-constraint 快 60–95%，审稿人无法用"只是启发式"攻击）
- ⑫ 的 IC 分析框架作为证明"菜单机制下说真话是最优反应"的模板

**创新点角度**：见第五章 Top1/Top2。

### 方向 D：共享充电与多主体（3 篇：⑲㉗㉘）

**研究主题**：公交场站闲置能力开放（⑲）、私桩 P2P 共享（㉗）、两公司共租（㉘）——资源归属多元后"预约"从技术问题变成合约问题。

**关键实证（㉗，367 加州家庭）**：
- 28% 愿当桩主 / 31% 愿租用；知晓率仅 15–25%
- **双方第一阻碍都是 liability（责任担忧 87%/77%）**；环保话术垫底（36–38%）
- 租户痛点：69% 怕找不到方便的桩、80%+ 怕桩不可靠 → 作者原话需要 "effective reservation systems"
- 价格缺口 12 个百分点；南加州（6 倍电价差）能成交、北加州难

**缺陷与留白**：㉗ 没测"什么机制能消除责任担忧"——**预约即合约（押金托管+爽约赔付）没人做过**；中国场景（公私同网、高密度小区）比加州更容易冷启动，是天然的场景差异化。

**我能复用什么**：㉗ 的 motivation 话术（用三成意愿 + liability 瓶颈论证"预约机制是共享充电的缺件"）；⑲ 的真实案例参数。

### 方向 E：不确定性方法工具（4 篇：⑨㉕㉙㉑）

**研究主题**：负荷不确定（⑨基线包络）、SOC+离站不确定（㉕）、到达与服务随机（㉙）、网络容量不确定（㉑）。

**方法与建模**：日前生成基线包络（⑨）、Wasserstein DRO→MILP（㉕，1000 辆 <30s）、MFVQ 流体休假队列闭式解（㉙）、运行依赖不确定集+改进 C&CG（㉑）。

**我能复用什么（重点是最轻量的三件）**：
1. ㉙ 的 **χ² 拟合检验模板**（到达 χ²=7.90 p=0.34 / 服务 χ²=3.63 p=0.89）——拿到任何订单数据第一步就做
2. **Little 公式 W=L/λ**——仿真结果交叉验证
3. ㉕ 的 **UEF 指标**与"主模型场景法/预算集 + 小算例 DRO 对照量化保守度"的组合拳
- ⚠️ 注意：㉕ 的 Wasserstein DRO **不能直接搬进调度 MILP**（逐样本约束爆炸）；低成本退路是预算不确定性集（⑲ 同款）

**创新点角度**：现有 DRO 全部对冲"负荷/离站"的物理不确定性，**没人对冲"策略性行为"的不确定性**——行为鲁棒 vs 分布鲁棒是可挖的概念创新。

## 五、创新点地图（核心章节）

### 5.1 全领域的"三条不成立"（所有创新点的总源头）

现有文献（含所有顶刊）几乎都假设用户：**① 准时（不迟到不早走）② 同质（或异质但不进决策模型）③ 诚实/理性（如实报告、守约、不策略行为）**。
- ⑱㉙ 把用户当被动工件；⑲⑳㉑㉘ 假设守约如实；㉒㉔ 把关键自报信息当外生真话；㉓ 证明了惩罚伤福利却没给出路。
- **任何一条被打开，都是一个可写的题。**

### 5.3 我推荐的主攻组合（Top 3 拼成一篇论文）

> **一句话定位**：在充电桩预约机制中，把车主行为异质（类型）与策略行为（谎报/爽约）内生进机制设计——用真实数据标定类型，用菜单+惩罚转移实现 IC，用硬窗/软窗+鲁棒做基线与兜底。
