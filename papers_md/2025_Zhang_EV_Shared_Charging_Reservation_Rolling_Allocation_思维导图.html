预约式动态滚动分配框架
（混合停车场）
场景 普通位 + 快充位 + 慢充位
动作 预约 + 15min 决策间隔滚动排位
创新 充电位共享给纯停车用户
难点 用户不准时 → 排班冲突
求解 MIP + Gurobi，15min 内出解
1研究主题▾
  • 一句话：混合停车场里同时调度停车与充电需求，靠预约 + 滚动分配 + 充电位共享提高收入与利用率
  • 混合停车场 = 普通车位 + 快充位 + 慢充位共存（hybrid parking lot）
  • 核心矛盾：充电位闲时空转 vs 普通车位不够用
  • 核心风险：用户早到／晚走 → 相邻用户抢同一车位
2研究背景与动机▾
  • 车多桩少：EV 增速 > 充电设施增速，找桩难抑制推广
  • 位被霸占：充满不走 + EV 免费停车政策 → 超时占用
  • 时空不均：热门站挤爆、冷门站闲置；峰谷差异大
  • 政策副作用：深圳 30%、杭州 15% 车位须配建充电 → 停车更难
  • 已有三条路线：抑制需求 / 增加供给（共享）/ 实时引导
3两个研究空白（Gap）▾
  • Q1：以往只做「纯停车预约」或「纯充电预约」，混合停车场一体化分配几乎没人做
  • Q2：用户不准时会让依赖精确时刻表的预约系统失效，缺鲁棒框架
  • 作者原创性①：首次同时刻画停车用户与充电用户的时间偏差
  • 作者原创性②：从「静态提前一天预订」走向动态在线实时重排
4研究目的与四条贡献▾
  • 目的：最大化净收入（总收入 − 冲突成本）+ 最小化总出行时间
  • ① 一体化动态分配框架 + 充电位共享机制（仿真验证）
  • ② 两阶段（先充电后停车）+ 动态滚动算法
  • ③ 不准时建模 → 最大冲突概率 ρmax → 反推时间缓冲（鲁棒）
  • ④ 杭州 1400+ 停车场 / 3000 万条记录 + 4 万条快充记录标定
5方法①：模型体系与基线▾
  • 四大基线：FCFS（到场抢位）／FBFS（先订先得，贪心）／DA（间隔内统一优化）／SO（提前一天全局最优＝理论上界）
  • 主模型 D-DRA：确定性动态滚动分配
  • 「滚动」= 可调请求在 Ii+1 ~ Ii+g−2 可被反复重排，腾位给新请求
  • 目标：max 收入 − 拒绝惩罚 − 出行成本（三目标加权，权重均取 1）
  • 决策间隔 ΔI = 15min → 一天 96 个间隔
6方法②：共享机制 + 两阶段▾
  • CASE 0 不共享（基准）｜CASE 1 完全共享
  • CASE 2 时长限制：停车时长 < β（450min）才可占用充电位
  • CASE 3 时间窗限制：到达落在 6–9 点或 14–17 点
  • CASE 4 时长—类型匹配：短停→慢充位，长停→快充位（δ=90min）
  • 两阶段 charge-first-park-second：先满足充电需求，剩余充电位才给停车
7方法③：鲁棒模型 R-DRA▾
  • 两类冲突：LL 晚走（前车不走）、EA 早到（后车干等）
  • 到达／离开时间 ~ 异质正态分布（假设分布已知）
  • 约束：Pr(Am ≤ Lm′) ≤ ρmax ⟹ μD > σD·Φ⁻¹(ρmax)
  • ρmax = 0.1 ⟹ 平均缓冲 ≈ 15 分钟
  • 三种实现：O 原始（最慢）／R 削减冗余约束（综合最优）／N 预加缓冲后跑 D-DRA（冲突最少、最快）
8实验、结论与讨论▾
  • 场景：4 个停车场 / 100 车位（普 50·快 40·慢 10）/ 需求 200–600
  • 小算例：R-DRA 净收入最高 1486.2，成功服务率 0.90（FBFS 仅 0.74）
  • 共享机制 uniformly 提升收入与利用率：CASE1/4 利 CSU，CASE2 利 SSR
  • 需求 > 350 后 D-DRA 收入碾压 FBFS；接受率高 ≠ 收入高
  • 缓冲倒 U 型：低压力最优 20min，高压力最优 15min
  • 局限：未做预约取消、未做建设成本/容量规划、分布未预测
  • 未来：用 深度强化学习 DRL 处理序贯决策
