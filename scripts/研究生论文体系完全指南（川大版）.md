# 研究生论文体系完全指南（川大版）

> 适用：四川大学研一新生 / 课题组有发小论文要求
> 整理时间：2026-09
> 注意：文中所有"要求"均为**参考与举例**，每年文件会更新，**一切以你所在学院/学位评定分委会最新文件和导师要求为准**。

---

## 一、先分清两套东西：大论文 vs 小论文

| | 大论文（学位论文） | 小论文（发表的学术论文） |
|---|---|---|
| 是什么 | 硕士/博士学位论文，毕业答辩用的那本 | 投到期刊/会议上公开发表的文章 |
| 谁来评 | 学校盲审 + 答辩委员会 | 期刊编辑 + 同行评审人 |
| 字数 | 硕士 3-5 万字，博士 8-15 万字 | 3000-10000 词不等 |
| 是否公开 | 入库（知网/万方），可申请保密 | 公开发表，有 DOI |
| 关系 | 大论文通常是把 2-3 篇小论文串成一个体系（川大很多课题组这样做，叫"章节式学位论文"） | |

**你课题组说的"发小论文"，指的就是后者。**

### 论文的"物种"分类

- **Article（论著/原创研究）**：含金量最高，有完整数据和方法。毕业、评奖基本只认这个。
- **Review（综述）**：不产生新数据，靠对领域的理解。一般要求"受邀撰写"，研一新手很难发，但顶刊综述地位很高。
- **Letter / Communication（快报/通讯）**：短小、突出一个亮点，审稿快。
- **Case Report（病例报告）**：医学常见，专业学位博士可用。
- **Conference Paper（会议论文）**：投国际会议（EI/CPCI 检索）。计算机、电子、自动化领域是主战场；生化环材医学基本不算数。
- **Preprint（预印本）**：arXiv / bioRxiv / SSRN / ChinaXiv。**不是正式发表**，但能占坑、防被抢发，多数期刊允许先传预印本再投稿。
- **专利、软件著作权**：川大很多学院允许用来**替代**论文满足授位条件，务必查清。

## 二、期刊"江湖等级"：三套评价体系并行

这是最让人晕的地方。记住一句话：**"是不是 SCI" 是身份问题，"几区" 是排名问题，"A/B/C 级" 是单位自己排的座次。**

### 1. 国际索引（身份：这个期刊进没进数据库）

| 简称 | 全称 | 覆盖 | 说明 |
|---|---|---|---|
| **SCI / SCIE** | 科学引文索引 | 自然科学、工程技术、部分医学 | 理工医科的硬通货 |
| **SSCI** | 社会科学引文索引 | 经济、管理、心理、社会学、教育等 | 社科的国际版 |
| **A&HCI** | 艺术与人文引文索引 | 文学、历史、哲学、艺术、语言 | 人文的国际版 |
| **EI Compendex** | 工程索引 | 工程技术 | 分 **JA（期刊）** 和 **CA（会议）**，含金量 JA >> CA |
| **CPCI**（原 ISTP） | 会议录引文索引 | 会议论文 | 认可度最低，多数单位不单独认 |
| **Scopus** | 爱思唯尔的文摘库 | 全学科 | 部分单位认 CiteScore |
| **PubMed / MEDLINE** | 医学文摘库 | 生物医学 | 医学口常挂嘴边 |

> 理工科一般：SCI Q1 > Q2 > Q3 > Q4 ≈ EI 期刊 > EI 会议 > 中文核心 > 普刊
> 人文社科一般：SSCI/A&HCI > CSSCI > 北大核心 > 普刊

### 2. 分区（排名：在同领域里排第几）

**JCR 分区（科睿唯安官方）**：按影响因子 IF 在同学科里**平均切四刀**
- Q1 = 前 25%，Q2 = 25-50%，Q3 = 50-75%，Q4 = 后 25%

**中科院分区（国内最认）**：按三年平均 IF **金字塔式切分**
- 1 区 = 前 5%（Top 期刊），2 区 = 6-20%，3 区 = 21-50%，4 区 = 后 50%

> ⚠️ 所以"JCR 一区"和"中科院一区"**不是一回事**。国内高校（含川大）奖励、毕业、评职称基本看**中科院分区**。查分区用微信小程序"期刊分区表"或图书馆入口。

**其他指标**：IF 影响因子、CiteScore（Scopus）、H 指数、SJR/SNIP。**不要迷信 IF**，粒度差异极大（数学 2 算高，材料 20 才算还行）。

### 3. 国内核心（中文期刊的身份）

| 体系 | 俗称 | 主管单位 | 覆盖 |
|---|---|---|---|
| **中文核心期刊要目总览** | 北大核心 / 北核 | 北大图书馆 | 全学科，约 2000 种，国内最通用（2023 版为第 10 版） |
| **CSSCI** | 南大核心 / C 刊 | 南大 | 人文社科，约 600 种，社科最权威（含来源期刊 / 扩展版 / 集刊） |
| **CSCD** | 中国科学引文数据库 | 中科院文献情报中心 | 自然科学/工程技术/医学，分核心库与扩展库，人称"中国的 SCI" |
| **中国科技核心** | 科技核心 / 统计源 | 中信所 | 科技应用类，约 2000 种，门槛相对低 |
| **RCCSE** | 武大核心 | 武大 | 分 A+/A/A- 等，部分单位参考 |

> 一本期刊可以同时是北大核心 + CSSCI（如《经济研究》）。**投之前一定去官网查最新版目录**，目录每 2-3 年更新，会掉出也会进入。

### 4. 学科内部目录

- **CCF 推荐目录**（计算机专属）：A/B/C 三类，分期刊和会议。国内计算机硕博的**实际标准**，比 SCI 分区更被认可。CCF-A 会议（如 CVPR、NeurIPS、SIGMOD）在计算机圈的地位 ≈ SCI 一区顶刊。
- **中国科协《高质量科技期刊分级目录》**：按 40+ 个学科领域分 **T1 / T2 / T3** 三级，越来越被高校采用。

### 5. 川大自己的分级（⭐ 最重要，学院文件里写的往往就是这套）

川大执行两套校内分级方案，**各学院/学位评定分委会直接引用它们**：

**理工医科**：《高质量科技期刊及学术会议分级参考方案（暂行）》（科研院，2021 年版）
成果分 **A 级 / A- 级 / B 级 / C 级 / D 级 / E 级 / F 级**
（早期版本叫《四川大学 SCI 期刊分级方案》，分 A~F 六级：A=国际顶级，B/C=一级学科顶级，D=二级学科前 15%，E=15%-50%，F=其余 SCI）
> 共同一作怎么认，方案里有明确规定。例如临床医学分委会：A 级允许所有共同一作获得资格，A- 级认前 3 位共同一作，B 级认前 2 位。

**人文社科**：《四川大学社会科学研究处哲学社会科学论文成果与应用成果分类参考方案（2022 年）》
期刊分 **A1 / A2 / B / C / D / E** 六级。A1 含 SSCI 一区、A&HCI 一区、《中国社会科学》、川大 SCI 分级 1-2 级等；A2 含 SSCI 二区 + 国内 22 种顶刊 +《新华文摘》全文转载。

**关键点**：这两个文件都有**纸质版/内部版**，公开网页上只有说明。最直接的获取方式是：
1. 问导师或师兄师姐要 PDF；
2. 去学院研办/科研科问；
3. 研究生管理系统里填报成果时，系统会给出下拉分级选项，**那个下拉框就是标准答案**。

## 三、川大：读研到底要发几篇？三层要求叠加

**不是学校统一规定一个数字，而是三层叠加，取最严的那个：**

```
第 3 层（最狠）：你课题组 / 导师的内部要求  ← 你真正要满足的
第 2 层：学院 / 学位评定分委会的授位条件
第 1 层（最松）：学校研究生院的基本要求
```

### 学校层面

近年教育部要求**破除"唯论文"**，学校层面普遍改为"**创新成果**"多元认定，即论文、专利、获奖、标准、咨询报告、工程贡献等**满足其一即可**。但注意：多元化的是"成果形式"，不是"不用出成果"。

### 学院层面（真实举例，看清楚差多大）

- **环境科学与工程（建筑与环境学院）**：硕士需"以第一作者、川大为第一署名单位发表**1 篇北大核心及以上**"，或"授权国家发明专利/软著 1 项（本人排前 2、导师第 1）"；博士需"1 篇以上 E 级刊物论文"，或 5 份教育部平台评阅意见均 ≥90 分，或省部级奖、行业标准、PCT 专利等。
- **临床医学（华西）**：按《高质量科技期刊及学术会议分级参考方案》分级。普通博士需 I 类或 II 类成果 1 项；硕博连读/直博需 I 类 1 项或 II 类 2 项。**学术学位博士文章类型须为 Article 或 Review**，专业学位博士可为 Article/Review/Case Report/Letter（须有数据）。
- **法学（法学院）**：硕士"公开发表或未发表的学术论文代表作 1 篇"，**或**参加 1 次国内外学术会议并发言——已经很宽松。

### 几乎所有学院都有的三条硬杠杠

1. **署名**：本人第一作者；或**导师第一作者、本人第二作者**（视为第一作者）。
2. **单位**：**四川大学为第一署名单位**。这是最容易翻车的地方——你要是挂了别的单位，学校不认。
3. **时间**：成果须为**在读期间**取得，且与学位论文内容相关；部分学院对"接收（Accept）"与"见刊（Online/Print）"的认定不同，有的认接收函+导师签字，有的必须见刊。

> ⚠️ **最容易被忽略的一条**：开题到答辩**不得少于 10 个月**（法学院文件明确写了，各院类似）。研二下学期才开题的话，时间非常紧。

## 四、你的三条行动线（本周内做完）

1. **找到本学院的《研究生申请学位学术成果基本要求》**
   路径：学院官网 → 研究生教育/研究生工作 → 学位/授位相关文件；或直接搜"XX学院 学位评定分委会 学术成果"。
2. **问导师要课题组内部要求**（这条比你查到的所有文件都管用）。
3. **问同门师兄师姐实际发了什么刊**——他们的路径就是你的下限。

同时去研究生管理系统（ehall.scu.edu.cn）看"学位管理 - 科研成果"模块，那里能看到成果分级的**下拉选项**，这是最权威的一手信息。

## 六、一篇论文从写到检索的完整流程

```
选题 → 文献调研 → 做实验/跑数据 → 写作 → 选刊 → 投稿
   → 编辑初审（可能被 Desk Reject，一周内拒稿）
   → 同行评审（1-3 个审稿人，1-6 个月，有的拖一年）
   → 决定：Accept / Minor Revision / Major Revision / Reject & Resubmit / Reject
   → 返修（补实验、回信写 Response Letter）
   → Accept → 签版权协议 → 排版校样（Proof）
   → Online First（有 DOI）→ 正式见刊（卷期页）
   → 被数据库收录（WoS/EI/知网），开检索证明
```

**时间真相**：从投稿到见刊，快则 2-3 个月，慢则 1-2 年。**"接收"到"能被检索证明查到"通常还有 1-6 个月延迟**。这意味着研三上学期还没被接收，就可能赶不上毕业。

**状态词速查**：Submitted → With Editor → Reviewers Invited → Under Review → Required Reviews Completed → Decision in Process → (Revise) → Accept。

**O A 版面费**：开源（Open Access）期刊要付 APC，常见 1500-4000 美元，有的顶刊更贵。问清课题组是否报销。**传统订阅制期刊一般不收版面费**，但部分中文期刊收审稿费/版面费。

**检索证明**：川大图书馆可出具"查收查引"证明（SCI/EI/CSCD/CSSCI 收录及引用情况），申请学位、评奖学金要用。图书馆官网有入口。

## 七、研一行动清单（12 个月）

| 时间 | 该干的事 |
|---|---|
| 研一上（9-12 月） | 上课拿学分；**每周精读 3-5 篇本方向近 3 年文献**；进组跟师兄师姐熟悉仪器/代码；建立文献库（Zotero）；开始写第一篇的文献综述草稿 |
| 研一寒假 | 确定研究方向；复现 1-2 篇关键论文的结果（这一步决定你后面能不能出活） |
| 研一下（3-7 月） | 跑出第一组可用数据；**把第一篇小论文的框架和图表做出来**；参加一次组会汇报；投稿一次国内学术会议练手 |
| 研一暑假 | 完成第一篇英文初稿；找导师和师兄改 2-3 轮 |
| 研二上 | 投出第一篇；**同时开题** |
| 研二下-研三上 | 第二篇；根据学院文件查漏补缺；预留至少 8-10 个月给返修和见刊 |

**最重要的一条**：论文是"写"出来的，不是"做"出来的。数据够讲一个完整故事就可以动笔，不要等到"完美"。

## 八、红线与避坑

- **一稿多投**：同时投多个期刊 = 学术不端，一旦被发现会被拉黑。被拒后才能改投。
- **重复发表 / 自我抄袭**：中文发过再翻译成英文发，多数期刊不允许（需在投稿时声明）。
- **图片造假、裁剪拼接、一图多用**：现在期刊普遍用 AI 查图，查出来终身留痕。
- **代写代投、论文工厂、买卖论文**：直接取消学位申请资格。
- **中科院《国际期刊预警名单》**：每年更新，被列入的期刊（多为"灌水"的 MDPI/Frontiers/Hindawi 个别刊）在川大很多学院评奖、授位时**不予认定**。投稿前务必查当年名单。
- **掠夺性期刊（Predatory Journal）**：发邮件狂轰滥炸邀稿、承诺"一周录用"、网址不像正规出版社、查不到 ISSN、不在 WoS/Scopus 目录里的，一律远离。
- **AI 写作规范**：国家自然科学基金委、科技部等明确**生成式 AI 不能列为作者**；使用 AI 辅助写作/润色须在方法或致谢中声明，各期刊政策不同（多数允许润色，禁止 AI 生成正文与图）。2023 年后各刊都加了相关条款。
- **署名权**：贡献大小次序在**动笔前**就和导师/合作者说清楚，事后最容易翻脸。
