# 28 确定性调度模型系统综述 —— 开工前必读

## 一句话

给"并行充电桩上调度 EV 常规充电任务"建了一个**相当一般化的确定性框架**，把所有变体维度列清楚。

## 这个框架的维度（我的建模查表清单）

| 维度 | 可选 |
|---|---|
| 时间与地点 | 固定 / 可选 |
| 决策时间范围 | 区间 / 环（环形时间，适合周期性） |
| 任务可否**抢占** | 可 / 不可 |
| 抢占的代价 | 是否有 setup 时间与成本 |
| 每个任务要求 | 给定**能量** → 决定充电时长 |
| 功率约束 | 充电桩总功率有上界 |
| 目标函数 | 桩成本 / 区位成本 / 能量成本 / 最大功率 / setup 成本 / 完工时间函数 |

**"常规充电任务"定义**：在同一时间、同一地点完成的充电任务。
典型场景就是**城市电动公交**（固定班次 + 充电调度）。

## 为什么现在就该读

我的路线是"**先做确定性基线模型**"。这篇告诉我：
- 这个基线**该包含哪些维度**
- 目标函数有哪几类
- 我**有没有遗漏的约束**

**在跑第一个模型之前翻一遍，能省掉大量返工。**
