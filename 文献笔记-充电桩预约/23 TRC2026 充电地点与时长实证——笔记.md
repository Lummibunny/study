# 23 充电地点与时长的实证模型（MDGEV）

## 一句话

用澳大利亚 EV 车主一周的充电数据，建 **多变量多离散分组极值模型（MDGEV）**，**同时**刻画"在哪儿充"和"充多久"。

## 关键方法知识点

**MDGEV = Multivariate Multiple Discrete-Grouped Extreme Value model**（Bhat et al., 2020）

- **多离散**：一次决策可以选多个选项（一晚上可能在 2–3 个地方充）
- **多分组**：把连续量（时长）离散成组
- 同时处理"地点"和"时长"两个维度，并处理不同充电地点之间的**相关性**

还加了**状态依赖变量**捕捉**习惯效应**：过去的充电选择会影响后续决策。

## 实证发现（可直接引用）

- 装了光伏的家庭更可能在家充，但**充得更短**
- 住大城市的更依赖非家充

## 我的价值

这是 TR-C 顶刊上的**行为实证范式**。如果我要做车主分类，"凭什么这么分"的答案可以从这类实证的**变量设计**里来。也提醒我：**分类特征不是拍脑袋的**，要来自真实数据的显著变量。
