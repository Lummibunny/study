# ① 预约式动态滚动分配（含不准时）

## 一句话

共享充电停车位的**预约 + 滚动分配**框架，把用户不准时用概率分布建模，鲁棒化后转成 MIP，并推导出**理论时间缓冲**。

## 为什么读它

**与你的题目重合度最高的一篇。** 预约 + 滚动 + 不准时 + 鲁棒，几乎就是你想做的东西。这既证明选题方向对（顶刊认可），也是警报——你的创新点必须在读完它之后重新校准，否则审稿人一句"与 Zhang et al. 雷同"就能摁住。

## 核心内容

1. 用户不准时（unpunctuality）→ 用概率分布刻画
2. → 鲁棒优化转化
3. → 转成混合整数规划 MIP 求解
4. 推导出**理论时间缓冲**：给定最大冲突概率下，相邻预约之间需要留多久

## 可复用的建模点

- **「不准时 → 概率分布 → 鲁棒转化 → MIP」** 这条链路，是方向②的标准打法
- **时间缓冲（time buffer）** 作为设计变量 —— 比"加惩罚项"优雅得多，可直接迁移到「日前预留多少容量」
- 滚动分配框架的论文结构与对比基线设置方式
