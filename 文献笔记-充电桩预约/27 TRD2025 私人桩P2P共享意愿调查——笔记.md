# 27 私人桩 P2P 共享的公众意愿

## 一句话

调查 367 个加州 EV 家庭对"私人充电桩点对点共享"的态度。

## 数据（可写进引言）

| 结果 | 数值 |
|---|---|
| 愿意**当桩主**（出租） | 约 28% |
| 愿意**租用** | 约 31% |
| 桩主最看重 | 租金收入 |
| 租户最看重 | 便利 + 省钱 |
| **双方最大阻碍** | **责任担忧（liability）** |
| 环保收益 | 大家都觉得不太重要 |

细分：独栋住户租用意愿更低；高里程、天天充电的人租用意愿更高。



**不是建模论文，是问卷实证。** 读它的好处：

1. 给"共享充电为什么难"提供**真实数据**（写引言/讨论用）
2. **最重要的启示**：**责任/违约风险才是共享的瓶颈**，不是技术也不是价格
   → 这正好呼应第 21 篇（违约惩罚机制）。**"预约机制"的学术价值就在这儿：把责任分配清楚。**
