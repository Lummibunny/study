# 基于卡车-无人机协同配送的双目标应急物资运送优化

---

## 总结

灾后初期，让**一辆卡车 + 一架无人机**组队送货，同时优化两个互相冲突的目标：**① 总物流成本最小**（钱），**② 灾民剥夺成本最小**（痛苦）。因为问题是 NP-hard 且剥夺成本是指数函数形式（非线性），作者改造了 NSGA-II 的**解码环节**（设计了一个最小剥夺成本标签算法）和**排序环节**（一个染色体解出两套方案），得到 INSGA-II，用 Matlab 在 10/20/50 个受灾点的算例上验证：协同模式完胜纯卡车模式，改进算法完胜传统 NSGA-II。

## 2. 研究背景

### 2.1 现实背景（数据链）

1. **灾害频发、损失巨大**：2020 年全球共发生 313 次自然灾害，波及 123 个国家和地区，造成 15082 人死亡、9896.67 万人受影响、直接经济损失 1700 多亿美元。
2. **快速响应是减损关键**，其中**应急物资的高效运送**是核心环节。
3. **现有运输方式有瓶颈**：目前灾后运送主要靠**卡车**；直升机、船舶只在特定场景能用（例如山区直升机飞行严重受限）。运输方式的低效和不灵活，已成为制约快速救援的瓶颈。
4. **新技术给了新选项**：无人机被视为下一代物流最有效的运输工具，但**电池电量和载重能力**限制了它单独使用。
5. **于是有了组合方案**：卡车-无人机协同配送（**STDD, synchronized truck-drone delivery**）——既吃到卡车的**大容量 + 长距离**，又吃到无人机的**高速 + 灵活**。2021 年亚马逊已开始研发可释放并控制配送无人机的新卡车，并申请专利。

### 2.2 学术背景：应急物流 ≠ 商业物流

作者特意点出了两者的差异，这是全文的立论支点：

| 维度 | 商业物流 | 应急物流 |
|---|---|---|
| 共同点 | 都要求**快速交付** | 同左 |
| 目标权衡 | 在**效率与成本**之间权衡 | 生命受威胁时，**对成本的容忍度更高** |
| 独特性 | — | 还要**尽可能减轻灾民因缺乏物资/服务所遭受的痛苦** |

> 这一条差异直接决定了：应急物流的模型里要有一个**"人"的目标**，而不只是"钱"的目标。

## 3. 文献回顾（这一节写得很好，可直接当综述素材用）

### 3.1 考虑"灾民痛苦"的应急物资运送

**痛苦的两种刻画方式**：

| 方式 | 做法 | 缺陷 |
|---|---|---|
| **剥夺成本直接表示法**（本文采用） | 源自福利经济学，把"因无法获得商品/服务造成人类痛苦的经济价值"定义为**剥夺成本**；同时考虑**未满足需求量**和**经历短缺的时间** | — |
| **代理方法** | 用未满足需求、公平限制、减少惩罚等代理指标 | **只看需求量，没有时间维度** |

**为什么要选剥夺成本直接法**：Holguín-Veras 等 [2]（*J. of Operations Management*, 2013）用数值实验证明，代理方法**不能正确考虑与交付决策相关的机会成本**，且**无法区分需求的紧迫程度**。

**已有研究脉络**：

| 文献 | 做法 | 本文的评价/定位 |
|---|---|---|
| Perez-Rodriguez 等 [3]（*Transp. Sci.* 2016） | 灾后库存-分配-路径问题，最小化运输成本 + 剥夺成本之和 | **单目标**；因模型依赖路径难求解，简化为"卡车每次只服务一个点就回配送中心"，**完全不考虑路径优化** |
| Pual 等 [4]（*TR-B* 2019） | 目标同上，也不考虑路径优化；把需求放宽为**随机需求**，研究灾前配送中心选址与物资分配 | **单目标**；按地震等级构建不同剥夺成本函数，建模为**鲁棒优化** |
| Serrato-Garcia 等 [6] | 最小化运营成本（选址+库存+运输）与剥夺成本**两个目标**，开发灾害决策支持系统 | **多目标**，但仍单一运输方式 |
| Zhu 等 [7] | 救援车辆解救受灾者的路径优化；对**同质/异质受灾者**分别建模，最小化运输成本 + 绝对剥夺成本 + 相对剥夺成本 | 多目标；区分了绝对/相对剥夺 |
| 朱莉等 [8] | 多目标应急物资动态调配；最短调配时长 + 最小绝对/相对剥夺成本 | 多目标 |

**小结性批评**：上述研究无论单目标还是多目标，**都以单一运输方式为主，极少研究卡车-无人机协同配送的应急物资运送**。但现实里很多受灾点（如山区小路）**卡车根本到不了**，协同配送能有效提高救援覆盖面。

### 3.2 卡车-无人机协同配送的路径问题

**经典设定（商业领域起源）**：无人机单位容量、飞行距离有限、卡车容量较大、**单卡车 + 单无人机**。

| 文献 | 贡献 |
|---|---|
| Murray 等 [9] | **首次提出并研究**该问题；提出两个 TSP 变体：**FSTSP**（flying sidekick TSP，卡车与无人机必须协作）与 **PDSTSP**（parallel drone scheduling TSP，无协作要求）；目标都是最小化完成所有服务返回配送中心的总时间 |
| Agatz 等 [10] | 从**集合覆盖**角度研究 TSP-D，建模为最小化总时间的整数规划，对 12 个顾客节点**精确求解** |
| Ottomanelli 等 [11] | 放宽"只能在顾客节点/配送中心会合"的假设——卡车可**沿路由弧线（在途）**发射/回收无人机 |
| Ha 等 [12] | 延续 FSTSP 假设，提出**最小化成本**的 TSP-D（目标含运输成本 + 等待成本）。**本文模型直接借鉴这篇的建模框架** |
| Ha 等 [13] | 同时最小化旅行时间和物流成本的**双目标** TSP-D |

**从"单-单"走向"多-多"**：多无人机 FSTSP [14]、多无人机多旅行商 [15]、多无人机多无人车协同 [16]、区域限制的卡车搭载无人机 VRP [17]、卡车-无人机动态协同路径 [18]、多无人机 TSP-D（成本最小）[19]、电池能耗随载重变化的联合取货 [20]、无接触式配送 [21]。

**已有"多车多无人机 + 多目标"的三篇文献（本文的主要对标对象）**：

| 文献 | 目标 | 目标函数形式 |
|---|---|---|
| Luo 等 [22] | 最小配送成本 + 最大客户满意度（单车多无人机） | 成本线性；满意度为线性决策相乘 → **非线性** |
| Zhang 等 [23] | 最小配送时间 + 成本 + 卡车能耗（多车多无人机） | 三个目标**均为线性** |
| Lu 等 [24] | 最小配送时间 + 最大需求满足率（多车多无人机） | **均为线性** |

> **本文的差异化卖点**：物流成本目标是线性的，但**剥夺成本这一目标是指数函数的积分形式**，目标更复杂、求解更具挑战性。

**灾害管理领域的（稀少）研究**：

- Fikar 等 [25]：模拟+优化的救灾决策支持系统，但**卡车和无人机各自独立配送**，不是协同。
- 彭勇等 [26]：新冠疫情背景下严重地区物资配送，最小化协同配送总服务时间，混合邻域搜索算法。**单目标**。
- Zhang 等 [27]：把协同系统用作**灾后评估工具**——无人机配摄像头收集路网信息，卡车充当**无人机的移动充电桩**，最大化信息收集价值。

> 注意 [27] 这个"卡车当移动充电桩"的设定，对你（充电桩方向）有迁移价值，见第 11 节。

### 3.3 研究空白（Gap）——一句话

> **无论在商业领域还是灾害管理领域，卡车-无人机协同配送的目标多为最小化运输成本或运输时间，尚无文献从灾民角度刻画受灾者承受的剥夺成本。**

## 4. 研究目的与贡献

### 4.1 目的

在突发自然灾害背景下，把 **STDD 模式**引入灾害救济，并建立**同时最小化物流成本与剥夺成本**的双目标路径优化模型，设计可实用的求解算法。

### 4.2 三条贡献（原文照录 + 我的解读）

1. **建模贡献**：针对 STDD 模式下**同时考虑物流成本和剥夺成本**的物资运送问题建模，并**详细刻画了剥夺成本的性质**。
   → 解读：核心是那个指数型剥夺成本函数及其积分、以及"非滞后行为"的处理。
2. **算法贡献**：针对剥夺成本函数的性质，在 INSGA-II 的**解码环节**设计了**最小化剥夺成本的解码算法**，从而有效寻找双目标的帕累托前沿。
   → 解读：标签算法 + 辅助图九元组，把指数目标可递推化，这是全文最硬的技术点。
3. **验证贡献**：数值分析说明，与仅卡车配送相比，STDD 模式的**非支配解集更优**；算法比较验证 INSGA-II 比传统 NSGA-II 更有效。

## 5. 模型（重点章节，逐条拆）

### 5.1 问题描述

- 灾害发生后，用**一架有效载重为 Q 的小型无人机** + **一辆卡车**协同，为某区域受灾点运送物资。
- 卡车与无人机**从配送中心出发，服务完所有点后返回配送中心**。
- "交付物资"定义为由卡车（或无人机）为该受灾点提供服务；**每个受灾点只能被服务一次**（要么卡车要么无人机）。
- 无人机飞行轨迹用**三元组 (i, j, k)** 表示：

| 符号 | 含义 |
|---|---|
| **i** | **发射节点**——无人机从卡车上起飞的点。每次发射前卡车都为无人机**更换新电池** |
| **j** | **目的地**——无人机送货的受灾点 |
| **k** | **会合节点**——卡车与无人机重新汇合的点；先到的一方要**等**另一方（保证同步运动） |

- **发射耗时 sL，回收耗时 sR**；无人机不飞行时停在卡车上被搭载前行。
- **可行三元组 (i,j,k) 的两个条件**：
  1. **飞行总时间 ≤ 无人机最大飞行时间 ε**。总时间 = i→j 飞行时间 + j→k 飞行时间 + **在 k 点等待卡车的时间**（假设无人机等待卡车时仍处于飞行状态 [12]）；
  2. 受灾点 j 的物资**需求重量 ≤ 无人机载重 Q**（超重的点只能由卡车送）。
- **一次飞行只服务一个受灾点**（电量与载重限制所致）——这也是作者自己在展望里列的第一个可放宽假设。

### 5.2 成本结构

#### (1) 物流成本（目标 1，线性）

由**运输成本** + **等待成本**两部分组成，均与距离/时间呈线性关系：

- 运输成本：`c1 · Σ Σ dij·xij`（卡车）+ `c2 · Σ (d'ij + d'jk)·yijk`（无人机）
- 等待成本：`α · Σ wi`（卡车等待）+ `β · Σ w'i`（无人机等待）

**关键约束**：会合时卡车与无人机**只有一方存在等待时间**，故
```
wi ≥ t'i − ti,   w'i ≥ ti − t'i,   ∀i ∈ VR
```

#### (2) 剥夺成本（目标 2，非线性——全文的灵魂）

**来源**：Holguín-Veras 等 [2] 指出个体剥夺成本与剥夺时间成函数关系，并通过**经济学实验**验证了"水"的剥夺成本概率密度函数：

```
γg(t) = e^(1.5031 + 0.1172t) − e^1.5031
```
（γg 单位：美元；t 单位：小时）

本文将其一般化为 `γg(t) = e^(g1 + h·t) − e^(g2)`，用 g1、g2、h 三个系数刻画。

**性质刻画（作者的假设）**：
- 本文研究**一次物资运送**的路径优化，属于**短期物资短缺**，故个体剥夺成本函数呈**非滞后行为**（non-lagging）特点；
- 假设**各受灾点人数已知**，且受灾区域灾民**同质**；
- 应急物资以**单位包装**存储（瓶装水、急救包等），**一单位物资 = 一个受灾者的救援需求量** [28]；
- 剥夺时间**从物资离开配送中心算起**（配送开始时刻为时间 0）；
- 若要把"配送开始前灾民已承受的痛苦"算进来，只需在剥夺成本目标函数里**加一个常数**，**不影响模型性质**（这是个很干净的处理）；
- **剥夺成本随时间的变化形态**：从物资离开配送中心 → 受灾点收到物资，这段时间里剥夺成本**逐渐增加**；收到物资后灾民不再痛苦，**剥夺成本降为 0**，并持续到本次运送结束。

**全区域剥夺成本**：
```
min Σ(j=1..n) ∫(0→φj) [ e^(g1 + h·t) − e^(g2) ] · πj dt
```
其中 **φj 为物资到达节点 j 所需时间**：卡车服务时 φj = tj，无人机服务时 φj = t'j；πj 为节点 j 的人口。

> 直观理解：这是"痛苦随时间指数增长"的累积面积，人口越多、到得越晚，代价越大且**越晚越陡**（指数项）。

### 5.3 完整数学规划（混合整数非线性规划，MINLP）

**参数**：
- `N = {1,...,n}` 受灾点集合；`V = {0,1,...,n,n+1}` 节点集（0 与 n+1 均为配送中心）
- `VL = {0,1,...,n}` 可发射无人机的节点集；`VR = {1,...,n+1}` 可回收无人机的节点集；`VD ⊆ N` 由无人机服务的节点集
- `dij` 卡车 i→j 行驶距离；`d'ij` 无人机 i→j 飞行距离
- `c1` 卡车单位距离运输成本；`c2` 无人机单位距离运输成本
- `g1, g2, h` 个体剥夺成本函数系数
- `P` **所有可行无人机飞行三元组**的集合：`P = {(i,j,k) | i∈VL, j∈VD, k∈VR, i≠j, j≠k, k≠i, τ'ij + τ'jk + w'i ≤ ε, q·πj ≤ Q}`
- `ε` 无人机最大飞行时间；`Q` 无人机最大载重；`q` 单位物资重量
- `πi` 节点 i 总人口；`M` 足够大的数
- `τij` 卡车 i→j 行驶时间；`τ'ij` 无人机 i→j 飞行时间
- `α` 卡车单位时间等待成本；`β` 无人机单位时间等待成本

**决策变量**：
- `xij ∈ {0,1}`：卡车路径是否包含 i→j
- `yijk ∈ {0,1}`：无人机路径是否包含三元组 (i,j,k)
- `pij ∈ {0,1}`：节点 i 是否在 j 之前被访问（且 p0j = 1）
- `ui`：节点 i 在卡车路径中的位置
- `ti / t'i`：卡车/无人机**到达**节点 i 的时刻；`ri / r'i`：**离开**时刻
- `wi / w'i`：卡车/无人机的等待时间

**目标函数**：
```
(1) min  c1·ΣΣ dij·xij + c2·Σ (d'ij + d'jk)·yijk + α·Σ wi + β·Σ w'i      [物流成本]
(2) min  Σ(j=1..n) ∫(0→φj) (e^(g1+h·t) − e^(g2)) · πj dt                  [剥夺成本]
```

**约束逐条解读（按功能分组，共 44 条）**：

| 约束 | 功能 |
|---|---|
| (3) | 定义 φj：卡车服务取 tj，无人机服务取 t'j（用 xij / yijk 加权） |
| (4)(5) | 每次会合**只有一方等待**（卡车/无人机等待时间的下界） |
| (6) | **每个节点只能被访问一次**（卡车或无人机二选一） |
| (7)(8) | 卡车**从配送中心出发并返回**配送中心 |
| (9) | **消除子环路**（MTZ 型） |
| (10) | 卡车**流平衡** |
| (11)(12) | 无人机**只能在卡车经过的节点**发射/回收（含配送中心处的特例） |
| (13) | 若无人机走 (i,j,k)，则卡车路径上 **k 的位置必须排在 i 之后** |
| (14)(15) | 每个节点**最多发射/回收无人机一次** |
| (16)~(19) | 用 pij 双向限定卡车路径上任意节点对 (i,j) 的**先后顺序**（(18)(19) 是配送中心处的特例） |
| (20) | **避免无人机从两次飞行三元组的中间节点发射** |
| (21)(22) | 卡车路径的**时间递推关系** |
| (23)~(28) | 无人机经过 (i,j,k) 时，i、j、k 之间应满足的**时间关系** |
| (29)(30) | 卡车 / 无人机**到达与离开会合节点**的时间关系（含 sL、sR 装卸时间） |
| (31) | 无人机**最大电量（续航）约束** |
| (32)~(42)(44) | 变量取值范围与 0-1 约束 |
| (43) | 被无人机服务节点的物资需求**满足最大载重限制** |

## 6. 算法设计（本文技术含量最高的一节）

### 6.1 为什么不用精确算法

**分支定界法** [29] 是求解该类问题的精确算法，但**最多只能求解 14 个节点的小规模单目标问题，且耗时 1 小时**。而灾害救济中"时间就是生命"，故必须上启发式。

### 6.2 总体思路

借鉴双目标 **INSGA-II** 算法 [30]（Wang 等），并**结合剥夺函数的特点重新设计解码环节**。

### 6.3 编码（关键设计决策）

- 问题需要两类决策：① 受灾点由卡车还是无人机服务；② 路径上节点的访问顺序。
- **但如果把两个决策同时放进解的表示里**，很难用简单的重组和变异生成子代，不利于算法迭代。
- **本文的做法**：染色体**只编码"所有点都由卡车服务的 TSP 路由"**（即一个访问顺序排列），**"哪些点交给无人机"推迟到解码环节再决定**。
- 例：染色体 `[0,1,2,3,4]`，表示从配送中心 0 出发，卡车依次访问 1、2、3，最后回到 4（0 与 4 是同一个配送中心）。

> 这是很典型的"**编码简化 + 解码承担复杂度**"的元启发式设计套路。

### 6.4 解码（本文最大创新点）

**Step 0：把剥夺成本目标等价变换为可递推形式**

```
Σ(j) ∫(0→φj) (e^(g1+h·t) − e^(g2)) · πj dt
  = Σ(j) [ (e^g1/h)·πj·e^(h·φj) − e^g2·πj·φj ] − Σ(j) (e^g1/h)·πj
```
令 `λ = e^g1 / h`，`η = e^g2`，则：
```
目标 ↔ min Σ(j) ( λ·πj·e^(h·φj) − η·πj·φj ) − Σ(j) λ·πj
```
因为人口 πj 已知，`Σ(j) λ·πj` 是**常数**，所以解码时只需考虑每个节点的 `λπj·e^(h·φj) − ηπj·φj`。
再把它拆成**前项** `λπj·e^(h·φj)` 与**后项** `ηπj·φj`，**两项都可递推**——这是标签算法能跑起来的前提。

**Step 1：构建辅助图 G = (V, A)**
- 弧集 A 由两部分组成：① 卡车行驶的所有弧段；② 所有可行的无人机飞行三元组。
- 每条弧用一个**九元组**表示：
  `(i, j, clij, cd_preij, cd_lastij, Πij, tij, rD, rT)`

| 分量 | 含义 |
|---|---|
| i | 卡车弧段起点 / 无人机三元组发射点 |
| j | 卡车弧段终点 / 无人机三元组会合点 |
| clij | 经过该弧产生的**物流成本** |
| cd_preij | 经过该弧产生的剥夺成本**前项** |
| cd_lastij | 经过该弧产生的剥夺成本**后项** |
| Πij | 该弧经过节点（不含起点）的**受灾人数之和** |
| tij | 经过该弧所需时间 |
| rD | 该弧中的**无人机路径** |
| rT | 该弧中的**卡车路径** |

两种弧的九元组计算：

- **卡车行驶弧段 (i,j)**：`clij = c1·dij`；`cd_preij = λπj·e^(h·τij)`；`cd_lastij = ηπj·τij`；`Πij = πj`；`tij = τij`；`rD = Ø`；`rT = {(i,j)}`
- **无人机三元组 (i,k,j)**（i 发射、k 服务、j 会合）：
  - 物流成本 = 卡车从 i 绕行到 j 的成本（跳过 k）+ 无人机 i→k→j 飞行成本 + 卡车等待 α·wj + 无人机等待 β·w'j
  - 剥夺成本前/后项 = 沿途**每个**被跳过/服务的节点的贡献按各自到达时刻累加（节点 k 的到达时刻为 `τ'ik + sL`）
  - `tij = max{ τ'ik + τ'kj + sL + sR , 卡车绕行时间 }`（取大者，体现同步等待）

**Step 2：标签算法（动态规划）**

- 节点 i 处的标签：`l = (cli, cd_prei, cd_lasti, cdi, ti, RD, RT, i)`
- **每个节点设两个标签**：`l^lcost_i`（到达 i 时**物流成本最小**的路径）与 `l^dcost_i`（到达 i 时**剥夺成本最小**的路径）。
- **初始化**：配送中心 0 的两个标签全为 0；终点 n+1 与其余节点初始化为 +∞。
- **扩展公式**（沿 TSP 路由的节点顺序依次推进）：
  ```
  clj      = cli + clij
  cd_prej  = cd_prei + cd_preij · e^(h·ti)     ← 乘上已有时间的指数因子，实现递推
  cd_lastj = cd_lasti + cd_lastij + η·Πij·ti
  cdj      = cd_prej − cd_lastj
  tj       = ti + tij,  RD[j] = RD[i] ∪ rD(i,j),  RT[j] = RT[i] ∪ rT(i,j)
  ```
- **支配策略**（比较两个情景 1 与 2 的 (cl, cd)，四种情况）：

| 情况 | 条件 | 处理 |
|---|---|---|
| ① | cl₁ ≥ cl₂ 且 cd₁ ≥ cd₂ | 情景 2 在两个标签上都支配 1 → 2 更新两个标签 |
| ② | cl₁ ≤ cl₂ 且 cd₁ ≥ cd₂ | 1 支配 lcost，2 支配 dcost → 各自更新对应标签 |
| ③ | cl₁ ≥ cl₂ 且 cd₁ ≤ cd₂ | 2 更新 lcost，1 更新 dcost |
| ④ | cl₁ ≤ cl₂ 且 cd₁ ≤ cd₂ | 情景 1 在两个标签上都支配 2 → 1 更新两个标签 |

- **复杂度**：时间与空间复杂度**均为 O(n³)**，是多项式时间算法；且实际中受无人机飞行时间与载重限制，可行三元组数量大大减少，性能更好。

### 6.5 为什么必须改 NSGA-II 的排序与拥挤度（INSGA-II 的核心）

**传统 NSGA-II 的局限**：它只能处理**一个染色体解码出一种方案**的情形——根据染色体的一对目标值做快速非支配排序和拥挤度计算。

**本文的特殊性**：每个染色体会解出**两套不同方案**——
- **R1**：以物流成本最低为目标解码得到的配送路径
- **R2**：以剥夺成本最低为目标解码得到的配送路径

两者通常**不同**，各对应一对 (物流成本, 剥夺成本)，即**一个染色体 → 两对目标值**。

**改进的快速非支配排序（3 步）**：
1. 计算每个染色体两种解码方案的物流成本与剥夺成本，按个体对应关系加入空集 H；
2. 用传统快速非支配排序给**两种解方案分别分配前沿等级**，并按前沿等级升序排序；
3. 每个个体的**非支配序 = 其两个解方案中前沿等级较小者的等级**。

**改进的拥挤度计算**：
- 先算**解的拥挤度**：两种解方案前沿等级相同时，分别记录；不同时，**只记录等级较小的那个解的等级**。排序后，首尾解的拥挤度初始化为 **+∞**，其余按传统方式计算。
- 再算**个体的拥挤度**：两种方案等级**相同** → 取两者拥挤度的**均值**；等级**不同** → 个体的拥挤度 = 等级较小解的拥挤度。

- 硬件：1.8 GHz Intel Core i5，8 GB 内存（**配置相当一般**，这也衬托了算法效率）

### 7.2 算例与参数（**可直接抄来复现**）

| D1~D5 | 50 | 10 000 km² | 10⁴ |

**距离度量**：卡车走**曼哈顿距离**，无人机飞**欧几里得距离**（两点间距离对两者不同）。

**算法参数寻优结果**：种群个体数 m ∈ {50,100,150}、重组概率 pc ∈ {0.93,0.95,0.97}、变异概率 pm ∈ {0.10,0.20,0.30}；在 10 个受灾点实例上各跑 10 次，以 HV 最大为准，最终选定：
> **m = 150，pc = 0.95，pm = 0.30**

### 7.3 评价指标

| 指标 | 类型 | 含义 |
|---|---|---|
| **Hypervolume (HV)** | 综合性一元指标 | 解集与参考点在目标空间中围成的**超立方体体积**；**越大越好**；同时评价**收敛性与多样性**（Zitzler 等 [31]） |
| **覆盖率 C(S1,S2)** | 二元指标 | S2 中的解**至少被 S1 中一个解弱支配的比例**；C=1 表示 S2 全被 S1 支配；**不需要真实帕累托前沿、不需要人为设参考集** |
| **Δlcost / Δdcost** | 自定义指标 | TSP-D 模式非支配解集中，物流成本（剥夺成本）**小于 TSP 模式最小物流（剥夺）成本的解所占比例**。100% 表示 TSP-D 的所有非支配解都优于 TSP 的最优解 |

### 7.4 结果一：TSP-D（协同）vs TSP（仅卡车）

| 实例规模 | C(S1,S2) | Δlcost 均值 | Δdcost 均值 | 解码时间占比 |
|---|---|---|---|---|
| N = 10 | **1**（全部） | 100.00% | 90.00% | 51.41% |
| N = 20 | **1**（全部） | 92.00% | 99.60% | 71.23% |
| N = 50 | **1**（全部） | 96.93% | 98.93% | 95.97% |

**结论要点**：
1. **不同规模下 C(S1,S2) 均为 1** —— TSP 模式（仅卡车）的所有非支配解，**全部被** TSP-D 模式的某些解支配。即：总能找到比纯卡车更省成本、也更低痛苦的协同方案。
2. **Δlcost 与 Δdcost 均值都在 90% 以上** —— 协同模式得到的非支配解中，90% 以上的解的**两个目标都低于**纯卡车模式的**最优值**（注意是比对方最好的还低，不是比平均低）。
3. **计算时间**：N=10 约 84 s，N=20 约 181–192 s，N=50 平均约 **1747 s ≈ 30 分钟**（最长 D1 为 2698 s ≈ 45 分钟）。
4. **对比基线**：Dell'Amico 等 [21] 用分支定界解 **14 个节点的单目标**问题耗时 **1 小时**；本文解 **50 个节点的双目标**问题仅约 **30 分钟**。
5. **解码时间占比随规模上升**（51% → 71% → 96%），因为解码复杂度 O(n³) 对规模敏感——**这是本文算法的性能瓶颈所在**。

### 7.5 结果二：INSGA-II vs NSGA-II

对比三种情形：本文 **INSGA-II**；以最小化物流成本为目标解码的 **NSGA-II-lcost**；以最小化剥夺成本为目标解码的 **NSGA-II-dcost**。

- **物流成本迭代图**：三者都随迭代下降并趋于稳定。**INSGA-II 最低** > NSGA-II-lcost > NSGA-II-dcost（最差）。
- **剥夺成本迭代图**：同样，**INSGA-II 的曲线位于最下方**（最低） > NSGA-II-dcost > NSGA-II-lcost（最差）。
  > 有意思的对称现象：单看某一个目标时，以该目标为导向解码的 NSGA-II 排第二，以另一目标为导向的排最差。
- **最终帕累托前沿对比**：**INSGA-II 的帕累托前沿整体位于 NSGA-II-lcost 与 NSGA-II-dcost 的下方**（同等条件下物流成本和剥夺成本都更小）。
- 结论：改进的**快速非支配排序 + 拥挤度计算**是有效的。

## 8. 结论

1. 验证了**卡车-无人机协同配送模式比仅卡车配送**的物流成本和剥夺成本**更低**。
2. 通过对比传统 NSGA-II 与改进 INSGA-II，发现**改进算法能得到更优的帕累托前沿**。

## 9. 局限与未来方向（作者自述，很重要）

| 方向 | 内容 |
|---|---|
| **① 前期环节缺失** | 灾后救济是系统问题，物资运送的前提是有合理的**物资分配方案**（配送中心**选址** + 配送中心与受灾点的**分配关系**）。本文**只研究了后期的路径优化**，未来应**同时考虑应急物资分配与运送两个环节**。 |
| **② 假设过强** | 可放宽的假设包括：**无人机每次只能服务一个受灾点 → 放宽为服务多个**；**允许卡车与无人机在节点以外的弧上会合**（Ottomanelli 等 [11] 已做过）。 |

**我补充的、作者没提但客观存在的局限**：
- **单卡车 + 单无人机**，规模受限（算例最多 50 点，1 万 km²）；
- **剥夺成本函数只有"水"的实验参数**，其他物资（药品、帐篷）的 g1/g2/h 无实证；
- **确定性模型**——需求、路况、无人机续航均假设已知，没有不确定性/鲁棒处理（一作方向是鲁棒优化，这恰好是她下一篇的水位线）；
- **同质灾民假设**——没有区分老人/伤病员等异质群体（Zhu 等 [7] 已区分绝对/相对剥夺成本）；
- **没有真实案例**，全部基于 Agatz 等 [10] 的合成算例。

| 目标数 | 多指标比较 | 单因变量 | **双目标** |
| 对你最有用的东西 | 滚动分配框架、鲁棒缓冲思路 | **复刻最快的出稿路线** | **双目标建模 + 启发式算法范式** |

> 三条线串起来的话：**② 告诉你用户怎么看充电服务 → ① 告诉你运营商怎么排资源 → ③ 给你一套"把人的痛苦写进目标函数 + 用启发式求解"的方法论**。
