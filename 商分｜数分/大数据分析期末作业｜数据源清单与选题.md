# 一、先定"选数据的四条硬标准"

期末作业的评分点通常不是模型多花哨，而是**问题—数据—方法—结论是否闭环**。所以选数据先过这四关：

| 标准 | 具体要求 | 不合格的样子 |
|---|---|---|
| 拿得到 | 能直接下 CSV/Excel，不用申请白名单、不用付费 | 要签保密协议、要跑实验室 |
| 看得懂 | 有字段说明文档（数据字典） | 爬下来的表只有中文列名，不知道单位 |
| 有得算 | 至少 2 个维度可交叉（时间×地区、用户×品类） | 只有一行全国总量 |
| 讲得出 | 数据背后有现实故事（政策、大促、疫情、旺季） | 纯随机模拟数据 |

体量参考：**1 万 ~ 100 万行**最舒服。几千行也能做，但要靠分析深度补；上千万行反而清洗会拖死你。

# 二、数据源清单（按"能不能马上开工"排序）

## A 类：官方宏观统计 —— 最适合做趋势 / 区域差异

| 平台 | 地址 | 有什么 | 备注 |
|---|---|---|---|
| 国家数据（统计局） | data.stats.gov.cn | 分省月度/季度/年度：GDP、社零、人口、固投、CPI | 可直接导出 Excel，缺点是粒度粗 |
| 国家邮政局 | spb.gov.cn → 政务公开 → 邮政行业运行情况 | **每月分省快递业务量/业务收入**、前 50 城排名、同城/异地/国际结构 | 网页表格，需复制或写爬虫；做物流选题的黄金数据 |
| 中国物流与采购联合会 | chinawuliu.com.cn | 中国物流业景气指数 LPI、社会物流总额、PMI | 月度时间序列，适合做指数分析 |
| 交通运输部 | mot.gov.cn → 数据 | 货运量、港口吞吐量、客运量（分省月度） | 和快递数据可交叉验证 |
| 中国充电联盟 EVCIPA | evcipa.org.cn | 月度公共充电桩保有量、分省分布、充电电量 | 若做新能源/充电选题必用 |
| 四川省统计局 | tjj.sc.gov.cn | 四川统计年鉴、市州数据 | 做"成渝/四川"本地选题时用 |

## B 类：竞赛 / 开源数据集平台 —— 拿来即用，有字段说明

| 平台 | 地址 | 说明 |
|---|---|---|
| 阿里云天池 | tianchi.aliyun.com/dataset | 4000+ 数据集。经典：**菜鸟—需求预测与分仓规划**、淘宝用户行为、阿里移动推荐 |
| 和鲸 Heywhale | heywhale.com | 中文数据集社区，交通/物流/共享单车类很多，可在平台内直接跑 notebook |
| DataFountain | datafountain.cn | 政务、交通类赛题数据，含 CCF BDCI 历年赛题 |
| Kaggle | kaggle.com/datasets | 英文但字段规范，搜 `supply chain` `delivery` `last mile` `logistics` |
| UCI ML Repository | archive.ics.uci.edu | 老牌基准数据集，适合做方法对比 |
| 滴滴盖亚 | gaia.didichuxing.com | 轨迹、订单、路况数据（申请制，适合想炫技的） |

## C 类：政府开放数据平台 —— 适合做时空 / 地理可视化

上海 data.sh.gov.cn ｜ 深圳 opendata.sz.gov.cn ｜ 北京 data.beijing.gov.cn ｜ 浙江 data.zj.gov.cn ｜ 成都 data.chengdu.gov.cn ｜ 广州 data.gz.gov.cn

内容多为：公交刷卡、停车场、充电桩点位、气象、交通卡口、POI。特点是**带经纬度**，能画热力图、做空间聚类，PPT 出图好看。

## D 类：自己采（加分项，但要合规）

- 高德 / 百度地图开放平台 API：地理编码、路径规划、POI 检索（有免费额度）
- OpenStreetMap + Overpass API：路网、设施点位
- 中国天气网 / 气象数据中心：和历史订单数据拼"天气—需求"关系
- 企业年报：巨潮资讯 cninfo.com.cn（免费），做上市物流公司经营分析

> 合规红线：只采公开、非个人信息数据；不绕过反爬；报告里注明采集时间、来源、字段含义；遵守 robots.txt。

## E 类：校内资源（很多人不知道）

川大图书馆已购：**Wind、CSMAR、中经网统计数据库、EPS、国研网**。校内 IP 直接进，能下到上市公司财务、物流行业面板数据。做"物流企业效率/绩效"类选题必须用它。

# 三、四个可以立刻开工的选题（数据 + 方法都写好了）

## 选题 1｜省域快递业务量的空间差异与影响因素（最稳，推荐新手）

- **数据**：国家邮政局 2019–2025 分省月度快递业务量与收入（自建，约 31 省 × 84 月 ≈ 2600 行）；国家统计局分省 GDP、社零、常住人口、人均可支配收入
- **分析**：① 描述性统计 + 可视化（东中西差距、季节性）② 面板回归 / 随机森林找影响因素 ③ K-means 聚类给省份分档
- **优点**：数据全公开、中文语境、结论好讲（"快递量与社零强相关，中西部增速快但基数低"）
- **代码量**：pandas 合并 + statsmodels/sklearn + matplotlib/seaborn，约 300 行

## 选题 2｜城市充电桩布局与充电需求预测（和你的研究方向一致，一鱼两吃）

- **数据**：EVCIPA 月度全国/分省充电桩保有量；成都/上海开放数据的充电桩点位；高德 POI（商场、写字楼、小区）+ 路网
- **分析**：① 空间分布核密度/热力图 ② 桩车比测算与供需错配识别 ③ ARIMA/Prophet/LSTM 做月度充电量预测
- **优点**：直接沉淀成你论文的背景章节和数据描述部分
- **风险**：城市级充电量数据不公开，只能做到"桩"这一层，需求侧要用代理变量（车流量/POI 密度）

## 选题 3｜电商仓配需求预测（用现成赛题数据，最省事）

- **数据**：天池"菜鸟—需求预测与分仓规划"（订单-仓-商品三级时序）
- **分析**：① 探索性分析（SKU 销量分布、大促波动）② 特征工程（滞后项、滑窗、节假日）③ XGBoost/LightGBM 预测 + 误差分解
- **优点**：数据现成、有官方评测口径、网上参考资料多（但要自己重写，别抄）
- **注意**：选这个一定要加"业务解释"章节，否则像调包

## 选题 4｜共享单车/网约车的时空需求分析（可视化最出彩）

- **数据**：纽约 Citi Bike 行程数据（公开、每月一个 CSV，单月百万级）；或国内某市公共自行车开放数据
- **分析**：① OD 流向图 ② 分时段/分星期需求热力图 ③ 站点聚类 + 需求预测
- **优点**：数据量大、图好看、方法通用（时空聚类、时间序列）
- **注意**：数据量控制在一个月内，否则电脑跑不动

# 四、常见坑

1. **别用"不明来源的爬虫数据"**——老师说"数据来源"时说不出处，直接扣分。
2. **别只做描述统计**。至少要有一个"预测/分类/聚类/回归"的建模环节，这是"大数据分析"和"统计分析"的区别。
3. **代码要能一键跑**：目录结构 `data/ → src/ → output/ → report/`，附 `requirements.txt` 和 `README.md`（怎么装、怎么跑、每步产出什么）。
4. **PPT 和报告的图必须同源**：所有图由代码生成并保存到 `output/figures/`，不要手工截图。
5. **报告结构建议**：背景与问题 → 数据来源与清洗 → 探索性分析 → 建模 → 结果与解释 → 局限与改进。
